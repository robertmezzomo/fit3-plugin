Fit3 Voz

Transforma a gravação do sensor do Galaxy Fit3 em áudio: ouça, veja o espectro e avalie se dá para entender a voz.

Origem

Captação

Tratamento do som

Forma de onda

0 samplitude

Espectrograma

tempo →0–800 Hz

A voz humana que se entende vive entre 300 e 3400 Hz. Se o brilho só aparecer na faixa de baixo, a gravação não guardou os agudos da fala.

Qualidade

Escolha um arquivo para começar.
Projeto fit3-plugin. A página só lê o arquivo no seu navegador; nada é enviado. O salvar/enviar do áudio fica para o app do celular.
